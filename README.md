### 🚀 Featured Projects

#### 🏠 UrbanNest — AI-Driven Property Rental System
> `Next.js` `TypeScript` `Spring Boot` `PostgreSQL` `WebSocket` `OpenAI API`

A scalable multi-role rental platform with AI-powered property recommendations using semantic search.
- JWT-based authentication with role-based authorization (Tenant / Owner / Admin)
- AI recommendation engine via OpenAI API for intelligent property discovery
- End-to-end booking system with real-time WebSocket updates

---

#### 💼 CareerConnect — AI-Powered Job Portal
> `React.js` `Node.js` `MongoDB` `OpenAI API` `Pinecone` `Google OAuth`

A full-stack job portal with RAG architecture for intelligent resume analysis and job matching.
- RAG pipeline using OpenAI + Pinecone for semantic resume-job matching
- Role-based dashboards for job seekers and companies
- Automated skill extraction and candidate ranking

---

#### ♻️ TrashRoute — Smart Waste Management System
> `React.js` `PHP (OOP)` `MySQL` `Google Maps API` `JWT`

A platform connecting households with waste processing companies via optimized routing.
- Smart pickup workflow with route optimization based on waste type and location
- Integrated Google Maps API for route planning
- PHPMailer for automated notifications
